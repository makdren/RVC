# Изменения

Все версии и файлы — в [релизах на GitHub](https://github.com/makdren/RVC/releases). Приложение обновляется само: о новой версии сообщит баннер на главном экране.

## 1.0.9 <Badge type="tip" text="последняя" /> {#v1-0-9}

<small>29 октября 2026 · [релиз](https://github.com/makdren/RVC/releases/tag/v1.0.9)</small>

- **Новый вид диалогов:** та же стеклянная панель, что у карточек, кнопки на всю ширину и понятные названия действий — «Добавить», «Применить», «Отключить», «Удалить» вместо «Да».
- **Выбор из списка с пояснениями:** режим работы, тип пинга, сортировка локаций и тема больше не переключаются по кругу касанием.
- **Одна отметка выбора во всём приложении** — в локациях, профилях маршрутизации, режимах и списке приложений.
- **Главный экран при подключении перерисовывается раз в секунду вместо трёх:** таймер и скорость обновляются одним кадром, живое стекло не перерисовывается без нужды. 10–13 кадров за 10 секунд вместо 29.
- Уведомление со скоростью не обновляется, пока скорость не меняется.

## Windows 1.1.0 <Badge type="info" text="Windows" /> {#windows-v1-1-0}

<small>29 октября 2026 · [релиз](https://github.com/makdren/RVC/releases/tag/windows-v1.1.0)</small>

Первая опубликованная версия RVC для Windows 10 и 11 (64 бит). Подробнее — в разделе [RVC для Windows](/guide/windows).

- **Установщик на русском:** лицензия с кнопкой «Установить», ярлыки в «Пуске» и на рабочем столе, запуск RVC в конце; 66 МБ.
- **Лёгкий:** окно открывается примерно за 3 секунды, в простое около 160 МБ памяти и 0,1 % процессора.

- **Те же подписки, что на Android:** Remnawave, Happ и INCY, HWID для лимита устройств (хеш от идентификатора установки Windows), карточка провайдера с трафиком, сроком и объявлениями, профили маршрутизации.
- **Режим VPN** на адаптере wintun: весь трафик ПК через туннель, маршруты и фильтры утечек DNS и IPv6 настраивает ядро Xray 26.10.21, локальных портов нет. Нужны права администратора. **Режим прокси** — без прав, с системным прокси Windows по желанию.
- **Интерфейс для ПК:** боковая навигация, локации с круглыми флагами, поиском и пингом, анимации по правилам Windows 11, тёмный заголовок окна.
- **Меню в трее:** подключение, время, пять лучших локаций с пингом — одним щелчком по значку.
- **Горячие клавиши:** Ctrl+Alt+V подключает и отключает VPN из любой программы; Ctrl+Enter, Ctrl+F, F5, Ctrl+V в окне.
- **Запуск вместе с Windows** и задача «без запроса UAC» для режима VPN.
- **Обновление из приложения** со сверкой SHA-256 установщика.
- Данные зашифрованы DPAPI ключом учётной записи Windows. В трее RVC занимает 10–20 МБ памяти.
- Пока нет: AmneziaWG и раздельного туннелирования по программам.

## 1.0.8 {#v1-0-8}

<small>27 октября 2026 · [релиз](https://github.com/makdren/RVC/releases/tag/v1.0.8)</small>

Обновление безопасности и скорости по итогам аудита.

- **Запуск примерно вдвое быстрее.** В APK встроен Baseline Profile: код запуска, главного экрана и настроек компилируется заранее при установке, первая прокрутка без рывков. Сохранённые данные шифруются ключом данных, который защищён ключом Android Keystore, — на запуск нужна одна операция Keystore вместо одной на каждый файл. Старые файлы переводятся на новую схему сами. Подробнее — в разделе [Производительность](/dev/performance).
- **Подписки только по https.** Подписки, профили маршрутизации и геофайлы из интернета загружаются только по `https`: по открытому `http` подписку можно было подменить по пути и подсунуть свой сервер, а HWID уходил открытым текстом. Для адресов внутри телефона и локальной сети (`192.168.*`, `10.*`, `*.local`) `http` работает как раньше.
- **Режим прокси:** при доступе из локальной сети пароль обязателен — у кого он был выключен, создастся при обновлении. Сам телефон (`127.0.0.1`, `::1`, `localhost` и домены, которые на них указывают) через прокси закрыт: устройство из Wi-Fi не доберётся до локальных портов других приложений. Подробнее — в разделе [Безопасность](/dev/security).

## 1.0.7 {#v1-0-7}

<small>27 октября 2026 · [релиз](https://github.com/makdren/RVC/releases/tag/v1.0.7)</small>

- **Режим прокси.** «Настройки» → «Режим работы»: VPN не включается, RVC слушает SOCKS5 и HTTP на одном порту — для приложений с настройкой прокси и для раздачи через точку доступа. По умолчанию только `127.0.0.1` и с паролем. Подробнее — в разделе [Режим прокси](/guide/proxy).
- **Несколько подписок листаются свайпом** по карточке провайдера на главном экране; список локаций показывает подписку на экране.
- **Импорт ссылок AmneziaVPN `vpn://`** — AmneziaWG, WireGuard и Xray.
- Вибрация после обновления подписок: подтверждение или ошибка.
- Чат в Telegram — [@rvcapp](https://t.me/rvcapp), ссылка в «О приложении».
- Исправлено: кнопка «Удалить» на экране подписок, раскрытие объявления открывало экран подписки, текст в настройках и у локаций стоял вплотную к переключателям и флагам, буквы логотипа сдвинуты влево.
- Профиль маршрутизации с новыми ссылками на геобазы применяется, даже если его `LastUpdated` старше.

## 1.0.6 {#v1-0-6}

<small>26 октября 2026 · [релиз](https://github.com/makdren/RVC/releases/tag/v1.0.6)</small>

- **Меньше нагрузки на батарею.** MTU туннеля по умолчанию — 8500: на скачивании процессор нагружается вдвое меньше (1,2–1,4 с на 100 МБ вместо 2,5–2,8 с). Профиль показал, что под нагрузкой время уходит на системные вызовы, по одному на каждый пакет, а при большем MTU пакетов впятеро меньше. Подробнее — в разделе [Производительность](/dev/performance).
- Старые установки переходят на новое значение сами; выбранное вручную не меняется.

::: tip Для провайдеров

:::

## 1.0.1 {#v1-0-1}

<small>26 октября 2026 · [релиз](https://github.com/makdren/RVC/releases/tag/v1.0.1)</small>

- User-Agent теперь всегда `RVC/<версия>`.
- Пинг «Через прокси (HEAD)» делает настоящий HEAD-запрос через сервер; при включённом чужом VPN TCP- и ICMP-пинг автоматически идёт через ядро.
- Автовыбор из XRAY_JSON (балансировщик `leastLoad`) корректно пингуется и подключается.
- Объявление провайдера: невидимые символы скрываются, кнопка не обрезается.
- Ровные отступы букв в логотипе, непрозрачная шапка экранов, «потянуть вниз» обновляет подписки.

::: tip Для провайдеров
Чтобы RVC получал полный XRAY_JSON (автовыбор, балансировщики, маршрутизация шаблона), добавьте в Remnawave правило `user-agent` → `^RVC` → `XRAY_JSON` — см. [Настройка Remnawave](/provider/#response-rules).
:::

## 1.0.0 {#v1-0-0}

<small>25 октября 2026 · [релиз](https://github.com/makdren/RVC/releases/tag/v1.0.0)</small>

Первая версия.

- **Протоколы:** VLESS (Reality, XTLS-Vision, xhttp, ws, gRPC), VMess, Trojan, Shadowsocks, Hysteria2, SOCKS5, HTTP, WireGuard и AmneziaWG. Ядро Xray-core 26.10.21, amneziawg-go 3.1.
- **Подписки Remnawave:** HWID для лимита устройств, имя и логотип провайдера, трафик и срок, объявления и баннеры, кнопки поддержки и сайта, профиль маршрутизации, раздельное туннелирование и другие заголовки.
- **Маршрутизация:** профили в формате Happ и INCY, ссылки `happ://routing/…`, autorouting, геобазы с урезанием по нужным тегам.
- **Главный экран:** большая кнопка, карточка провайдера, список локаций с пингом, индикатор белых списков «БС».
- Плитка в шторке, виджет, ярлыки «Подключить» и «Отключить», уведомления провайдера, обновление из приложения.
- **Безопасность:** никаких открытых портов на `127.0.0.1` (встроенный TUN ядра), защита от утечек DNS и IPv6, kill switch, шифрование данных ключом Android Keystore, подтверждение действий из внешних ссылок.

SHA-256 сертификата подписи: `1b535fa3e4eba253cbde3bb264369da02d61961c4bb4ea46e5bbd0cb73ecce4e` — у всех версий один и тот же.
