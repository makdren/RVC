# Производительность

Замеры RVC 1.0.3 на vivo PD2536 (Android 16, Wi-Fi), одна подписка Remnawave, локация «Автовыбор» (XRAY_JSON), 26.10.2026.

| | RVC 1.0.3 |
| :-- | --: |
| Размер APK (arm64) | 16,4 МБ |
| Холодный запуск (среднее из 3) | 211 мс |
| Память с подключённым VPN (PSS) | 98 МБ |
| Процессы / потоки | 1 / 67 |
| Кадров за 10 с на главном экране при подключении | 38 |
| CPU на 100 МБ трафика (тест скорости Cloudflare) | 3,2 с |
| CPU в фоне, простой (медиана из 3 по 60 с) | 2,3 % ядра |

Скорость через туннель — около 80 Мбит/с на загрузку: она упирается в сервер, а не в клиент.

**Что это значит.** Приложение маленькое, быстро запускается и занимает мало памяти. Интерфейс рисует кадры только когда на экране что-то меняется: открытый главный экран почти не тратит батарею. Пакеты идут через TUN-вход Xray, без локальных прокси-портов (см. [Безопасность](/dev/security)); этот стек расходует процессор чуть заметнее остального, и его оптимизация — в планах.

Как мерили: CPU — сумма `utime+stime` всех процессов приложения из `/proc/<pid>/stat`; память — `dumpsys meminfo`; кадры — `dumpsys gfxinfo`; запуск — `am start -W`. Простой в фоне зашумлён трафиком других приложений.
