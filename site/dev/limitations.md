# Ограничения

- Зашифрованные ссылки `happ://crypt4/…` и `crypt5/…` не поддерживаются: ключ шифрования не опубликован. `incy://crypt1` поддерживается.
- Форматы sing-box и Clash/Mihomo не поддерживаются — используйте XRAY_BASE64 или XRAY_JSON.
- Не реализованы заголовки `hide-settings`, `subscription-pin`, `subscriptions-collapse`, темы оформления и `providerid`-статистика.
- Маршрутизация не действует для AmneziaWG.
- Платных API и серверов RVC нет: все возможности провайдера доступны любой подписке сразу через заголовки.
