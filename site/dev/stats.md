## Откуда цифры

RVC **ничего не отправляет разработчику**: в приложении нет аналитики и счётчиков для разработчика. Для VPN-клиента это вопрос приватности и незаметности — любой собственный сервер статистики выдавал бы пользователей.

Цифры берутся из открытых счётчиков GitHub Releases:

- **Скачивания APK** — сколько раз скачан каждый файл релиза: со страницы релиза и из встроенного обновления.
- **Проверки обновлений** — сколько раз скачан `update.json`. Одно устройство может запрашивать его несколько раз при открытии приложения, ручной или фоновой проверке. Счётчик отражает число запросов к этому файлу и не показывает число уникальных устройств.

GitHub хранит только накопленные значения. Поэтому раз в сутки workflow «Статистика» сохраняет снимок в ветку `stats` репозитория (файл `stats.json`), а эта страница считает приросты по дням.
