## Откуда цифры

RVC **ничего не отправляет разработчику**: в приложении нет аналитики, идентификаторов и счётчиков. Для VPN-клиента это вопрос приватности и незаметности — любой собственный сервер статистики выдавал бы пользователей.

Цифры берутся из открытых счётчиков GitHub Releases:

- **Скачивания APK** — сколько раз скачан каждый файл релиза: со страницы релиза и из встроенного обновления.
- **Проверки обновлений** — сколько раз скачан `update.json`. Каждая установка RVC запрашивает его раз в сутки, поэтому прирост за день примерно равен числу активных установок. Офлайн-устройства и выключенные телефоны в этот день не учитываются.

GitHub хранит только накопленные значения. Поэтому раз в сутки workflow «Статистика» сохраняет снимок в ветку `stats` репозитория (файл `stats.json`), а эта страница считает приросты по дням.
