# Что означает «БС»

**БС** означает «белые списки». В таком режиме оператор ограничивает доступ к интернету, оставляя доступными отдельные сайты. Значок RVC рядом с логотипом показывает результат проверки текущей сети.

| Значок | Что удалось проверить |
| :-- | :-- |
| **без БС** | Открылась одна из зарубежных страниц. |
| **БС** | Яндекс ответил, а зарубежные страницы не загрузились. Это признак возможного ограничения. |
| **нет сети** | Нет доступного подключения или проверочные сайты не ответили. |
| **БС ?** | Не удалось получить результат напрямую. Например, Android не предоставил доступ к отдельной сети при включённом VPN. |
| **БС…** | Идёт проверка. |

Нажмите на значок, чтобы повторить проверку. Если появился статус **БС**, попробуйте локацию, которую ваш провайдер выделил для такого режима. Часто она называется «LTE» или «БС».

## Как работает проверка

RVC проверяет доступность Яндекса и пробует загрузить целиком страницу Google, Wikipedia или тестовый файл Cloudflare. Короткого ответа сервера недостаточно, поскольку некоторые ограничения проявляются только при загрузке содержимого.

Проверка оценивает доступность нескольких сайтов. Медленная сеть или сбой этих сайтов могут повлиять на результат.
