# Белые списки

Бейдж рядом с логотипом показывает, ограничил ли мобильный оператор интернет **белыми списками** — режимом, при котором открываются только разрешённые российские сайты.

| Бейдж | Значение |
| :-- | :-- |
| «без БС» (зелёный) | Ограничений нет |
| «БС» (оранжевый) | Оператор включил белые списки: зарубежные сайты не открываются, Яндекс открывается |
| «нет сети» | Не открываются ни зарубежные сайты, ни Яндекс |

## Как проверяется

При белых списках зарубежные сайты не молчат: короткие ответы проходят (поэтому Android и пишет, что интернет есть), а тело страницы почти не скачивается — оператор душит соединение после первых килобайт.

Поэтому RVC напрямую, мимо VPN, **скачивает зарубежную страницу целиком** (Google, при неудаче — Wikipedia и Cloudflare, 120–260 КБ без сжатия) и проверяет `yandex.ru`. Таймаут — 7 секунд.

| Зарубежная страница | Яндекс | Бейдж |
| :-- | :-- | :-- |
| Скачалась целиком | — | «без БС» |
| Не скачалась | Отвечает | «БС» |
| Не скачалась | Не отвечает | «нет сети» |

Замер на мобильной сети с включёнными белыми списками: за 8 секунд Google, GitHub и Wikipedia отдали лишь 70–110 КБ, а `yastatic.net` — 87 КБ за 0,2 секунды.

Проверка запускается при открытии приложения, при смене сети и раз в 15 минут, пока открыт главный экран (каждая проверка — около 200 КБ трафика). Нажмите на бейдж, чтобы проверить заново.

::: tip Что делать при белых списках
Подключитесь к серверу, который провайдер выделил для работы при белых списках (часто такие серверы подписаны «LTE» или «БС»).
:::
