# Белые списки

Бейдж рядом с логотипом показывает, ограничил ли мобильный оператор интернет **белыми списками** — режимом, при котором открываются только разрешённые российские сайты.

| Бейдж | Значение |
| :-- | :-- |
| «без БС» (зелёный) | Ограничений нет |
| «БС» (оранжевый) | Оператор включил белые списки: Google недоступен, Яндекс открывается |
| «нет сети» | Не открывается ни Google, ни Яндекс |

## Как проверяется

RVC обращается напрямую, мимо VPN, к трём адресам Google (`www.google.com`, `www.gstatic.com`, `connectivitycheck.gstatic.com`) и к `yandex.ru`. Таймаут — 8 секунд.

Если ответил хотя бы один адрес Google, пусть и медленно, белых списков нет: при белых списках Google не отвечает совсем, а медленный ответ говорит о плохой сети или медленном DNS.

Проверка запускается при открытии приложения, при смене сети и раз в 5 минут, пока открыт главный экран. Нажмите на бейдж, чтобы проверить заново.

::: tip Что делать при белых списках
Подключитесь к серверу, который провайдер выделил для работы при белых списках (часто такие серверы подписаны «LTE» или «БС»).
:::
