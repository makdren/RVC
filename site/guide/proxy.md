# Режим прокси

Обычно RVC работает как VPN: весь трафик телефона идёт через туннель, а локальных портов нет. В **режиме прокси** VPN не включается — RVC поднимает SOCKS5- и HTTP-прокси на одном порту, и его указывают там, где нужно.

## Когда это нужно

- **Одно приложение через сервер, остальные — напрямую.** Например, Telegram или браузер с настройкой прокси.
- **Раздача на другие устройства.** Ноутбук или телевизор подключаются к точке доступа телефона и указывают прокси телефона.
- На телефоне уже работает другой VPN, и второй поднять нельзя.

## Как включить

«Настройки» → «Режим работы» → **Прокси**. Затем нажмите большую кнопку на главном экране — разрешение на VPN не понадобится.

| Настройка | Что делает |
| :-- | :-- |
| Порт | По умолчанию `10808`; SOCKS5 и HTTP на одном порту |
| Доступ из локальной сети | Прокси слушает не только `127.0.0.1`, но и адреса Wi-Fi и точки доступа — для других устройств |
| Пароль | Логин `rvc` и случайный пароль. Без пароля прокси может использовать любое приложение на телефоне |
| Адрес для подключения | Адреса, порт, логин и пароль — нажмите, чтобы скопировать |

На главном экране под статусом показывается адрес прокси.

## Пример: Telegram

«Настройки» → «Данные и память» → «Прокси» → «Добавить прокси» → SOCKS5: сервер `127.0.0.1`, порт `10808`, логин и пароль из настроек RVC.

## Ограничения

- Маршрутизация профиля работает так же, как в режиме VPN: российские сайты идут напрямую, остальное — через сервер.
- AmneziaWG в этом режиме недоступен: ему нужен собственный туннель.
- Это единственный режим, в котором RVC открывает порт. Оставьте пароль включённым, а доступ из локальной сети включайте только на своей точке доступа.
