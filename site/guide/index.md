# Начало работы

RVC работает на Android 8.0 и новее. Приложение не использует сервисы Google, поэтому подходит и для телефонов без них.

## Установка

Откройте [последний релиз](https://github.com/makdren/RVC/releases/latest) и скачайте файл под свой телефон:

| Файл | Для каких телефонов |
| :-- | :-- |
| `RVC-x.y.z-arm64-v8a.apk` | Почти все современные телефоны — **берите этот** |
| `RVC-x.y.z-armeabi-v7a.apk` | Старые 32-битные телефоны |
| `RVC-x.y.z-universal.apk` | Подходит всем, но весит больше |
| `RVC-x.y.z-x86_64.apk`, `-x86.apk` | Эмуляторы и редкие планшеты на Intel |

При первой установке Android попросит разрешить установку из браузера или файлового менеджера — это нужно один раз. Дальше RVC [обновляется сам](/guide/updates).

## Добавление подписки

Ссылку на подписку даёт провайдер: в личном кабинете, на странице подписки или в Telegram-боте.

- **Из буфера.** Скопируйте ссылку и нажмите на главном экране **«Из буфера»**.
- **Кнопкой на странице подписки.** Ссылки `happ://add/…`, `incy://…` и `rvc://add/…` открываются в RVC сразу; приложение спросит, добавить ли подписку.
- **Вручную.** Кнопка **+** в шапке → «Ввести ссылку». Сюда же можно вставить ссылки серверов (`vless://…`, `hy2://…`), конфигурацию WireGuard / AmneziaWG или несколько ссылок сразу.
- **«Поделиться».** Текст со ссылкой можно отправить в RVC из любого приложения.

После добавления на главном экране появится карточка провайдера: имя, логотип, остаток трафика, срок подписки, кнопки поддержки и сайта. Если провайдер прислал объявление, оно будет под карточкой.

## Подключение

Нажмите большую кнопку вверху экрана. При первом подключении Android покажет запрос на создание VPN — нажмите «ОК». Под кнопкой появятся статус «Подключено», время, скорость и кнопка **«Проверить»**: она измеряет задержку до интернета через туннель. Успешное подключение подтверждается лёгкой вибрацией.

Под статусом всегда видно, к какому серверу подключится кнопка: флаг, имя и пинг. Нажмите на эту строку — список прокрутится к выбранной локации.

Все локации всех подписок перечислены прямо на главном экране, выбранная отмечена галочкой. Нажмите на другую — если VPN включён, переключение произойдёт сразу. Кнопка с лупой открывает поиск по локациям.

**Пинг.** Потяните экран вниз — обновятся и подписки, и пинг. Замеры старше получаса показываются серым, чтобы старые цифры не выглядели свежими.

::: tip Другой VPN
В Android одновременно работает только один VPN. Если включён VPN другого приложения, RVC предупредит об этом на главном экране: при подключении RVC тот VPN отключится.
:::

- **Шапка неподвижна:** логотип, бейдж белых списков и кнопки всегда под рукой, список прокручивается под ней.
- **Бейдж «без БС» / «БС»** рядом с логотипом — [индикатор белых списков](/guide/whitelist).
- **Колокольчик** — сообщения провайдера (push-уведомления).
- **Потяните экран вниз**, чтобы обновить подписки.
- **Нажатие на карточку провайдера** открывает список подписок: обновить, переименовать, скопировать ссылку, удалить. При удалении подписки, через которую сейчас идёт VPN, туннель отключается.

## Настройки

| Раздел | Что там |
| :-- | :-- |
| Подключение | Маршрутизация, раздельное туннелирование, kill switch, системный «Постоянный VPN», автоподключение при открытии и после перезагрузки, переключение на другой сервер при сбое |
| Сеть | Локальная сеть мимо VPN, IPv6, анализ трафика (sniffing), фрагментация TLS, MTU, скрытие значка VPN |
| Подписки и пинг | Автообновление, обновление и пинг при открытии, [тип пинга](/guide/locations#типы-пинга), сортировка |
| Уведомления | Push-сообщения провайдера, напоминание об окончании подписки |
| Оформление и устройство | Тема, HWID (нажмите, чтобы скопировать), «О приложении» |

Провайдер может заранее задать часть настроек [заголовками подписки](/provider/headers#поведение-приложения).
