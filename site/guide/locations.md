## Список локаций

Серверы подписки показываются с круглыми флагами стран. Флаг берётся из эмодзи в начале имени (`🇩🇪 Германия`), а если эмодзи нет — из названия страны (`Germany`, `Нидерланды`). У сервера без страны — значок глобуса.

**Автовыбор** (молния) — это сервер из XRAY_JSON-шаблона провайдера с балансировщиком: ядро само выбирает самый быстрый из перечисленных серверов и переключается, если один перестал отвечать. Чтобы автовыбор приходил целиком, провайдеру на Remnawave нужно [одно правило](/provider/#response-rules).

Под именем — описание от провайдера или протокол и транспорт (`VLESS · xhttp`). Серверы с меткой `only Wi-Fi` видны только в Wi-Fi, `only Mobile` — только в мобильной сети.

## Пинг

Кнопка **«Пинг»** проверяет все серверы. Зелёное число — задержка в миллисекундах, «нет» — сервер не ответил.

### Типы пинга

Выбираются в «Настройки» → «Тип пинга» (провайдер может задать свой заголовком `ping-type`).

| Тип | Что измеряет | Когда выбирать |
| :-- | :-- | :-- |
| Через прокси (GET) | Полный запрос к `generate_204` через сервер | По умолчанию: показывает, что сервер действительно пропускает трафик |
| Через прокси (HEAD) | То же, HEAD-запросом | Чуть меньше трафика |
| TCP | Время установки TCP-соединения с сервером | Быстрая проверка доступности |
| ICMP | Классический ping | Только если сеть пропускает ICMP |

::: warning ICMP часто блокируется
Многие Wi-Fi-роутеры и операторы режут ICMP целиком — тогда «нет» будет у всех серверов. RVC это заметит и предложит выбрать TCP или «через прокси».
:::

Если включён VPN другого приложения, TCP и ICMP идут через него и показывают его задержку (часто 1 мс). В этом случае RVC автоматически меряет через ядро.

## Переключение при сбое

С включённой настройкой «Переключаться при сбое» RVC раз в минуту (пока приложение открыто; в фоне — реже) проверяет туннель. Если сервер перестал отвечать, VPN переключается на лучший по пингу сервер той же подписки.
