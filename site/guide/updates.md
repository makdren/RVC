# Обновление приложения

RVC проверяет новую версию в фоне при каждом открытии приложения. Если обновление доступно, на главном экране появляется компактная плашка. Нажмите «Подробнее», чтобы увидеть изменения и состояние загрузки. Проверить вручную: «Настройки» → «О приложении» → «Проверить обновления».

В окне подробностей видны текущая и новая версии, размер APK и список изменений. Прокручивайте заметки внутри окна. Нажмите **«Обновить»**, чтобы скачать APK под ваш процессор и открыть системный установщик. Во время загрузки показаны объём, процент и скорость. Затем RVC проверит файл и подпись. При первом обновлении Android попросит разрешить RVC устанавливать приложения.

## Проверки перед установкой

Скачанный файл устанавливается, только если:

1. его SHA-256 совпадает с опубликованным в релизе;
2. имя пакета — `com.makdren.rvc`;
3. номер версии совпадает с объявленным;
4. **сертификат подписи совпадает с установленным приложением**.

Подменённый или чужой APK установить не получится. Подписки и настройки при обновлении сохраняются.

## Windows {#windows}

RVC для Windows проверяет обновления при запуске и раз в 12 часов в релизах `windows-vX.Y.Z`. Новая версия скачивается по кнопке «Скачать» и ставится кнопкой «Установить и перезапустить» — только если размер и SHA-256 архива совпали с опубликованными. Подробнее — в разделе [RVC для Windows](/guide/windows#updates).

Что изменилось в каждой версии — на странице [Изменения](/changelog). Все версии и исходный код — в [релизах на GitHub](https://github.com/makdren/RVC/releases).
