## Скачать

Откройте [последний релиз](https://github.com/makdren/RVC/releases/latest) и выберите файл ([что нового](https://rvc.rowny.online/changelog)):

| Файл | Для каких телефонов |
| :-- | :-- |
| `RVC-x.y.z-arm64-v8a.apk` | Почти все современные телефоны — **берите этот** |
| `RVC-x.y.z-armeabi-v7a.apk` | Старые 32-битные телефоны |
| `RVC-x.y.z-universal.apk` | Подходит всем, но весит больше |
| `RVC-x.y.z-x86_64.apk`, `-x86.apk` | Эмуляторы и редкие планшеты на Intel |

Дальше приложение обновляется само: о новой версии придёт уведомление, а перед установкой RVC сверит контрольную сумму и подпись APK.

## Как пользоваться

1. Скопируйте ссылку на подписку из личного кабинета или бота провайдера.
2. Откройте RVC и нажмите **«Из буфера»** — или нажмите кнопку добавления на странице подписки: RVC откроется сам.
3. Нажмите большую кнопку. При первом подключении Android попросит разрешение на VPN. Под кнопкой видно, к какому серверу идёт подключение.

Все локации видны прямо на главном экране с круглыми флагами и пингом: нажмите на нужную, чтобы переключиться. Лупа открывает поиск, жест «потянуть вниз» обновляет подписки и пинг.

## Возможности

- **Протоколы:** VLESS (Reality, XTLS-Vision, xhttp, ws, gRPC), VMess, Trojan, Shadowsocks, Hysteria2, SOCKS5, HTTP-прокси, WireGuard и AmneziaWG (1.5, 2.0, 3.x). Полные JSON-конфигурации Xray с балансировщиками.
- **Подписки Remnawave:** User-Agent `RVC/<версия>` (в Remnawave добавьте [Response Rule](https://rvc.rowny.online/provider/#response-rules) `^RVC → XRAY_JSON` с `additionalExtendedClientsRegex`, чтобы приходили описания серверов), HWID для лимита устройств, имя и описание провайдера, трафик и срок, объявления и баннеры, ссылки на поддержку и сайт, автообновление по интервалу провайдера.
- **Маршрутизация:** по умолчанию российские сайты идут напрямую, реклама блокируется. Поддерживаются профили маршрутизации Happ и INCY (`happ://routing/…`, `incy://routing/…`, autorouting): профиль провайдера приходит вместе с подпиской, применяется и обновляется сам.
- **Раздельное туннелирование:** банки и госуслуги можно вывести из VPN — они будут работать через обычную сеть.
- **Индикатор белых списков:** бейдж «БС» показывает, ограничил ли оператор интернет белыми списками. Проверяется полной загрузкой зарубежной страницы — при белых списках короткие ответы проходят, а данные нет.
- **Режим прокси:** SOCKS5 и HTTP на одном порту вместо VPN — для отдельных приложений и раздачи через точку доступа, с паролем.
- **Быстрый доступ:** плитка в шторке (долгое нажатие открывает приложение), виджет на рабочий стол, ярлыки «Подключить» и «Отключить» на иконке.
- **Уведомления провайдера** и напоминание об окончании подписки — без Google-сервисов.
- **Оформление:** «живое стекло», круглые флаги стран, неподвижная шапка, светлая и тёмная темы, плавная прокрутка на 120 Гц и анимации, которые не тратят батарею в покое.
- **Без телеметрии:** приложение ничего не отправляет разработчику; [статистика](https://rvc.rowny.online/dev/stats) строится по открытым счётчикам GitHub Releases.

## Лёгкий и экономный

Замеры RVC 1.0.6 на vivo PD2536 (Android 16, Wi-Fi), подписка Remnawave, локация «Автовыбор»:

| | |
| :-- | --: |
| Размер APK (arm64) | 16,4 МБ |
| Холодный запуск | 203 мс |
| Память с подключённым VPN | 96 МБ |
| Процессы / потоки | 1 / 65 |
| CPU на 100 МБ трафика | 2,5 с |
| CPU в фоне, простой | 0,8 % ядра |
| Кадров за 10 с на главном экране при подключении | 38 |

Интерфейс не перерисовывается, пока на экране ничего не меняется, поэтому открытое приложение почти не тратит батарею. С 1.0.6 MTU туннеля по умолчанию 8500: системных вызовов на трафике впятеро меньше, процессора на скачивании — вдвое. Скорость упирается в сервер, а не в клиент. Подробнее и сравнение с INCY и Happ — на странице [«Производительность и сравнение»](https://rvc.rowny.online/dev/performance).

## Безопасность

- **Никаких открытых портов.** RVC не поднимает локальные SOCKS/HTTP-прокси на 127.0.0.1: трафик идёт через встроенный TUN ядра. Другие приложения не могут найти прокси сканированием портов и узнать через него IP сервера.
- **Без утечек.** DNS разрешается внутри туннеля, IPv6 не уходит мимо VPN, при сбое туннель не снимается (kill switch).
- **Данные зашифрованы** ключом из Android Keystore: подписки, ключи серверов и настройки не лежат в открытом виде. Резервное копирование данных приложения отключено, журналы ядра в релизе выключены.
- **Ссылки не выполняются молча.** Добавление подписки, импорт маршрутизации и отключение VPN по внешней ссылке требуют подтверждения.

Подробности — в [документации](https://rvc.rowny.online/dev/security).

## Для провайдеров

Для Remnawave достаточно одного правила в Response Rules. Имя и логотип провайдера, трафик и срок, объявления, баннеры, профиль маршрутизации и настройки приложения задаются заголовками подписки. Полный список заголовков, формат маршрутизации, deep links и push-уведомлений — в [**документации для провайдеров**](https://rvc.rowny.online/provider/).
